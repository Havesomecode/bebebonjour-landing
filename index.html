Notre méthode

Vous racontez. Nous composons. Vous validez.

  1. 01

    Votre demande

    Vous partagez les informations essentielles, la langue et le contexte souhaités. Vous donnez votre consentement à la publication et aux courriels, puis saisissez le mot de passe de l’offre pour une demande offerte.

  2. 02

    La composition

    La première version est composée, publiée et envoyée automatiquement avant relecture humaine. Si vous choisissez l’audio, la narration Cedar est créée dans cette même étape.

  3. 03

    Votre accord

    Vous relisez le résultat depuis votre lien privé. Une correction relance la création ; vous approuvez ensuite la version corrigée pour recevoir le courriel final.

Commencer ma demande

La demande ne déclenche aucun paiement automatique. Le mot de passe de l’offre permet une création offerte, sans paiement enregistré. Nous vous confirmons la suite avant toute étape payante.

Après la première version

Vous gardez le dernier mot.

Votre annonce est accessible à toute personne disposant de son lien non indexé. Gardez votre adresse courriel et votre lien de révision privés. Vous pouvez demander une correction ; le courriel final est envoyé après votre approbation. Le délai dépend du contenu et des langues choisies.

Avant de commencer

Les étapes claires, dès votre demande.

Que se passe-t-il après l’envoi ?

Lorsque le formulaire confirme l’envoi, votre demande est prise en charge. La première version est créée, publiée et envoyée automatiquement avant révision humaine. Le courriel contient votre lien privé pour relire, demander une correction ou approuver l’annonce.

Quand le paiement a-t-il lieu ?

Aucune carte n’est demandée dans le formulaire. Le tarif Essentiel est de 39 €. L’offre accessible avec son mot de passe est gratuite ; aucun paiement n’est enregistré. Nous vous confirmons la suite avant toute étape payante.

Le formulaire ne s’ouvre pas ?

Le bouton ouvre notre formulaire dans cet onglet. Rechargez cette page, puis réessayez. Si un envoi est encore en cours ou si vous attendez sa confirmation, ne transmettez pas une seconde demande.

Comment vos informations sont-elles utilisées ?

Uniquement pour préparer, relire et livrer votre annonce. Avec votre consentement, les informations du faire-part sont publiées à son lien non indexé, consultable par toute personne qui le reçoit. Votre adresse courriel et votre lien de révision restent privés.

Quand les courriels sont-ils envoyés ?

Le premier courriel est envoyé automatiquement avant révision humaine. Le courriel final est envoyé après votre validation finale. Une demande de correction relance la création, puis nécessite votre approbation pour cet envoi final.
